# 可检验的创新构思模式（不是固定答案表）

以下是作者自行总结的跨学科启发式工具；不代表复制或完整实现 ResearchStudio 的 15 种/31 个子模式，也不代表已由顶会统计验证。

1. **矛盾消解**：两篇可信文献在同一协议下出现相反结论 → 排除数据/统计混淆 → 提出可区分的中介机制。
2. **边界反例**：方法在一个条件下反复失败 → 识别其不可满足的假设 → 构造更弱前提的方法或定理。
3. **反事实诊断**：现有指标不能告诉我们模型为何正确 → 干预一个因子，对比可解释的行为变化。
4. **观测单位修正**：全局平均掩盖异质性 → 明确为什么更细粒度可观测且带来决策差异，避免粒度切香肠。
5. **表示不变性修正**：现有不变性损坏任务相关变化 → 设计可检验的保持/忘记条件。
6. **因果识别改进**：相关性不能支持因果归因 → 构造可识别的干预或负面控制。
7. **不等价简化**：已有复杂机制其实能由一个低成本规则近似 → 给出必要性边界，或反过来提出更简单方法。
8. **训练—部署条件错位**：学习时依赖的标签/时序在测试不可用 → 明确重写信息集合与协议。
9. **错误传播控制**：早期不确定估计递归积累 → 设计可停止、回退或纠正的更新策略。
10. **测量与基准缺陷**：指标无法检测真正失败 → 提出有效性、泄漏及复现实验的严谨评测。
11. **资源—性能边界**：同等预算下方法选择不同 → 控制总训练、测试计算和人工标注成本。
12. **理论假设放宽**：现有定理边界过强/太松 → 改变前提，提供证明和不可规避的反例。

候选 Idea 生成时必须写出：`源证据 → 失败/差异 → 假设 → 区别于最简强对手的机制 → 独有预测 → killer test`。不允许只填模式编号而跳过核验。
