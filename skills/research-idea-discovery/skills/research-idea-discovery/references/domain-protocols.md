# 不同研究类型的证据与验证适配器

**此表仅在用户选定对应领域时启用。** 不是学科限制；若遇到新领域，以其真实研究方法重新定义指标与实验标准。

| 范围 | 需要查清 | 最小反证或危险基线 |
|---|---|---|
| 机器学习/计算机视觉 | 训练与测试数据可见性、数据分割、模型规模、预算、公平性、强基线与开源状态 | 同 backbone、同计算/监督预算下对比简化机制；区分统计波动与实际提升 |
| Domain Generalization | 目标域训练阶段是否可见、源域数量、未见类和 open-set 条件 | 不使用目标数据的强 baseline；换一组偏移后仍成立吗 |
| Test-Time Adaptation | 测试标签是否可用、在线流式顺序、重置策略、单样本/批量、更新对象 | entropy、norm/stat updates、简单筛选；检查标签泄漏、延迟和灾难性漂移 |
| Multimodal / VLA / Robotics | 每种模态和机器人状态、动作接口、控制频率、闭环/离线评测、安全与仿真差异 | 去掉特定模态或重排模态；闭环失效分布是否改变而非只涨离线分数 |
| 理论计算机科学/数学 | 明确假设、定义、定理和证明、与已知下界/特例关系 | 构造反例、验证边界条件、能否由现有定理平凡推导 |
| 软件系统/网络/安全 | 工作负载、资源瓶颈、威胁模型、测试环境与可复现性 | 最简单工程优化是否等价；极端 workload / adversary 下失效吗 |
| 生物/医学 | 样本来源、伦理许可、混杂、重复样本、外部队列及临床终点 | 泄漏检测、阴性对照、独立队列；不把统计相关性当临床因果 |
| 材料/化工 | 试样批次、测量误差、工艺参数、晶相/形貌/性能因果链、对照和重复次数 | 控制温度/组分/工艺变量，重复实验；单张显微图不等于总体证据 |
| 社会科学 | 研究设计、变量操作化、识别假设、代表性、伦理 | 安慰剂检验、替代识别策略、预趋势/稳健性/外部效度 |
| 新领域 | 从领域官方方法论文抽取证据质量规则，不臆造 | 寻找该领域最小可证伪检验与最强竞争解释 |

跨领域创新不能用“其他学科已经存在但本学科没提过”直接判定高新颖性：需证明迁移的假设、机制或验证协议确有实质变化，并审查本领域隐藏的相近工作。
