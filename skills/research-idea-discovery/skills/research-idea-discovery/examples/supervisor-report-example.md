# 教学用导师报告片段：模态失效的类间证据（假设性案例，不是研究结论）

**导师判断：NEEDS_EVIDENCE。** 值得先做一个失效诊断，但没有足够证据证明“关系级证据”优于普通不确定度，也没有核实数据与代码能在你机器上跑起来。今天先核对一套现成音视频分类数据、公开可运行的检查点。

**一句话 Idea：** 摄像头还在拍，某两类已经看不清时，模型不应该因为自己仍然很自信，就继续强化那两个类别之间的区别。

**例子（玩具数字，不是任何论文实验结果）：** 两个音视频样本都输出 dog=0.95。A 的剩余音频中狗叫很清楚；B 的剩余模态只有环境噪声，狗/猫实际证据不足。但现在尚不知道无标签算法能否可靠区分 A 和 B，这就是研究的最大技术风险。

**动机：** 置信度并不直接测量当前输入的类别可区分性；需要先测实证失败，不可宣称所有 TTA 都用置信度更新。

**潜在贡献（只在实验支持后成立）：** ①揭示高置信与任务证据可用性分离的可重复现象；②设计能在无标签条件下比置信度/冻结更准确控制更新的最小方法。不要为了凑第三点说“提出一个新 benchmark”。

**故事线（待验证）：** 受损输入 → 某些类别对失去辨别证据 → 现有适应是否错误更新？ → 若真，检验是否有无标签可观测代理信号 → 仅在代理信号支持时更新 → 实验比较源模型/冻结/简单筛选和现有强基线。

**具体落地（均需核验）：** 首先调查 DASP 使用的相应公开数据和预训练权重、是否实际可下载、代码是否在现有环境跑通。不要仅凭论文写了 VGGSound-C 就称可复现。验证前不应确定 ImageBind 或 AV-HuBERT 为兼容骨干。

**第一步 E0：** 读取官方数据/许可/检查点 → 在小规模合法样本上跑 Source → 构造同样强度不同信息保留的受控失败 → 比较无更新/更新前后预测 → 判断是否存在超出输入损坏本身的负适应。如果没有，停止围绕“错误更新”的这条机制故事；如果简单冻结解决，重新考虑是否需要新方法。

**大白话总结：** 这不是研究“模型有没有信心”，而是先查清“模型是不是在没有足够依据时，还把自己的猜测当知识继续学”。
